Voice agents and playgrounds

Models

Mobile and touch

  • Clearer moderation feedback: a dedicated banner explains content-moderation rejections

Voice Agent Builder

  • "Improve with Grok" keeps refining your agent after creation, and a new Speech tab adds pronunciation and keyword controls
  • A new Statistics tab charts call volume and tool usage

Chat Playground v2

  • Attach files by drag-and-drop, attach Collections to search your documents, and generate images with the image_generation tool
  • Richer responses: improved tool-call cards, inline citations, and backend-driven reasoning-effort options

Voice Library and voice cloning

Settings redesign
