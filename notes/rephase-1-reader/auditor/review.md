## Supported conclusions

- **Coverage omissions are source-linked.** The publisher builds reviewed JSON from cover headline/deck, closing synthesis, summary paragraphs, and spec package fields (`survey_weekly_semantic_publication_v2.py:499-526`; builder at `survey_reader_surface_gate_v2.py:841-892`). The renderer at `:286-361` also emits anchors, frontmatter heading/lede/scope notes, final heading, plan section labels, result-only Claim Boundaries, date/window text and citations. The ten mutation categories and two covered controls accurately describe the prototype's function boundary. A citation-key change is an output/citation-identity witness, not a separately proven reader-prose change. Publication validation constrains several values upstream; the experiment does not prove that all arbitrary mutations are valid CLI inputs.
- **The derivation gap is real at the inspected boundary.** Review loading checks the named reviewed file's actual bytes (`survey_reader_surface_gate_v2.py:1003-1022`), while Gate evaluation separately scans the primary and structured files (`:1160-1174`, `:1253-1304`). Gate revalidation at `:1499-1560` verifies each saved file and review but does not reconstruct primary source from reviewed JSON. A caller-asserted output hash cannot establish that missing relationship.
- **The prototype supports a mechanism, not a complete contract.** Its exact rerender comparison rejects stale output and its digest check rejects changed reviewed input. The manually written `emitted_texts` projection and one synthetic fixture are not exhaustive schema, semantic, renderer-dependency, or profile validation. The production Gate is unchanged. These limits are consistent with leaving B3 open.
- **Direct-primary is a distinct capability to preserve and prove.** The review schema/loader can name and hash primary TeX; it does not require JSON. `survey_reader_publication_v2.py:638-703` forwards such a persisted review through the generic Gate. This supports a proposed exact-primary route, but does not establish dedicated route regression coverage, Special/Retrospective completion, or supporting-source semantic closure. The current Gate still must be strengthened to require the route's exact primary identity. Root correctly avoids inferring complete Special support.
- **Rejecting a full-argument semantic envelope is justified as a design decision.** Renderer `:322` hashes the whole result into a comment. Schema-permitted nonreader fields, including `runner.run_reference`, therefore affect exact TeX identity without necessarily changing reader prose (`draft-v2-result.schema.json`; `survey_drafting_v2_base.py:612-622`). Binding all arguments to semantic review would couple that judgment to build/provenance churn. This establishes a concrete coupling risk, not measured lifecycle cost or proof that every metadata change can safely reuse all approvals.

## Actionable evidence/design qualifications

1. **Qualify the current metadata mutation.** The probe adds a top-level `internal_validation_note`, forbidden by the Draft Result schema's `additionalProperties: false`; its overall fixture also bypasses Draft validation. It is a valid renderer-function illustration, not a valid production-input counterexample. Root should state this explicitly or use a schema-permitted nonreader field, while retaining the synthetic/non-CLI qualification. The source-level full-result hash independently supports the concern; no production workflow claim is needed to reject the shortcut.
2. **Bind the Gate to the stage-selected manuscript explicitly.** Worker correctly identifies a connected responsibility not explicit enough in the original root obligations. At `survey_stage_validation_v2.py:508-513` and `:558-563`, Gate validation receives issue/profile but no exact selected manuscript. Its internal scanned-file checks alone cannot establish that it belongs to the manuscript selected by the stage. The implementation contract and regressions should require this exact binding at both admission sites, including a wrong-manuscript same-issue/profile negative. This is a source-inspection conclusion, not a newly executed full-stage exploit.

Neither item requires broad redesign or another test run to support the present stop. Their disposition should be retained in closeout; this report does not certify later unreviewed edits.

## Remaining boundary

Bibliography values and source notes can affect meaning; supporting TeX and styles can emit content. The primary-only probe neither binds their full closure nor demonstrates their semantic coverage. Defining reader versus constrained provenance inputs, identifying the renderer's trusted dependency boundary, and specifying direct-primary supporting scope are necessary before claiming a complete repair. Existing exact-source/PDF publication review and Reader-Surface review have different contracts; apparent overlap does not authorize silent reuse or removal of independent judgment.

No all-profile viability, actual semantic/Human review, CI completion, Windows execution, publication, historical release invalidity, adoption authority, or net lifecycle saving is established here. The bounded design stop is supported; final implementation and fixed-candidate acceptance remain future work. No seven-point PASS is assigned.
